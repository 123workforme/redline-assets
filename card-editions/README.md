# Halloween card artwork

These are source illustrations, transparent frame layers and art masks for Redline's Halloween ’26 editions. The bot keeps card IDs, layouts, prices and rendering code in `redline-bot`; this repository owns the image files.

The bot pins an assets commit and verifies image byte counts and SHA-256 checksums before rendering. Do not overwrite a released image without also updating the bot's pinned manifest.

Collections: Ghost Circuit, Midnight Cathedral, Night Bat and Seven Crowns. The RX-7 is the FD3S, not the FC. Schumacher uses the approved original portrait. Masks clip artwork to the designed opening; alpha outside the frame is retained.
