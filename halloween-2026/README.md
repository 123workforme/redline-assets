# After Dark ’26 artwork

Reusable frames are in `frames/`; `afterdark-banner.png` is the profile banner. Spirit Ticket emoji exports are available at 32, 64, 128 and 256 pixels; use the 128 px transparent PNG for Discord emoji uploads.

Event dates, reward ownership, prices, the application emoji ID and gameplay code live in `redline-bot`. This repository stores only the artwork. Featured edition layers live in the sibling `card-editions/` directory.
